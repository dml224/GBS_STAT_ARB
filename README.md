# Gaussian Boson Sampling and Statisitcal Arbitrage for Clustering

This repository contains the simulations used for our paper on clustering assests in statistical arbitrage portfolios using Gaussian boson sampling.

It includes the main packages and example raw and processed data in the ```packages and data``` directory. It also includes some useful examples of the code used in the ```simulations``` directory. We are happy to provide other parts of code upon reasonable request.
