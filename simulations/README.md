# Simulations

This file contains the building block code used in the simulations. There is some code for processing data ```parse-loss_returns.py```, figure generation ```plot_multi_year.py```, clustering stocks ```some_clustering_algorithms.py```, and a gbs function ```gbs_sampling.py```. Some files are dependent on functions that aren't in the file itself, but they should be clear enough to deduce.

Code for the explicit statistical arbitrage strategy is not available and is left for the reader to create with help from the paper. Instead we share a useful blogpost that covers the main idea: https://financialnoob.substack.com/p/statistical-arbitrage-with-graph and the associated GitHub Repo: https://github.com/financialnoob/pairs_trading/blob/fbf7753c36765421d7d6498d4072338ae5904929/22.graph_clustering/22.graph_clustering_stat_arb.ipynb
