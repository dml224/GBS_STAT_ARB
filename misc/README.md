# Packages and Data

Details about package versions can be found in requirements.txt.

Stock price data and Fama-French Factors were taken from Wharton Research Data Services (WRDS): https://wrds-www.wharton.upenn.edu/
The data used in the paper was for non-commercial research purposes only. 

Alternative sources for data can be acquired from Yahoo Finance (yfinance package), .csv files on the internet, or synthetic data can be made for quick testing.
